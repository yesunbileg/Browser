# Browser

Browser tools and extensions.

## AIWise original-menu fix

[AIWise local patch](aiwise-patch/) uses the installed original AIWise extension as its donor. It preserves the original menu, tabs, Bookmarks and Settings, then adds local Claude account names and confirmed free-message reset times. The original vendor assets remain local; this repository contains the patch code.

The earlier [standalone tracker](claude-account-limits/) supplies the observation logic. Its redesigned popup is not used by the original-menu patch.
